# Trick catalog (ลูกเล่น)

Every effect in the catalog, with **when** to use it. One row = one reusable unit: in CapCut it is copied from the reference draft; in HyperFrames/Remotion it becomes one template component.
Source: measured from P'Ohm's own CapCut edits.

## How to pick
1. Label every beat of the cut transcript: hook / setup / proof / twist / lesson / button / listener-line / reaction / laugh / list / number / contrast / question / pain-word.
2. For each beat take the trick from the table whose **Trigger** matches. No trigger match = plain card, no trick.
3. Limits per clip: joke SFX at most 1; comic effects only on gags; red cards rare (~1 per clip).

## Cutting and camera
| Trick | Trigger | Spec |
|---|---|---|
| Jump cut on breath/filler | every pause | N: median 1.7-2.3 s · B: tight mode, gaps >= 0.3 s, edges -0.05 s, detect -24 dB >= 0.28 s |
| Micro-cut stutter | right before a punchline | 3-5 cuts of 0.2-0.5 s |
| Zoom punch ramp | rhetorical question / punch | scale 1.07 -> 1.28 -> 1.49, ~0.25 s each, then speed lines |
| Punch-in on listener | listener reacts or asks | scale 2.1-2.7, x -1.1...-1.7, y 0.1-0.2, straight cut |
| Framing change without audio cut | every shot | main cam zoom 1.25-1.83 at varied levels |
| Second-camera switch | every ~4 shots | DJI cam, zoom 1.27-2.15 |
| Hook pulled to front | strongest 3-4.5 s sentence | moved from mid-take to 0 s |
