# Repository history cleanup

The repository history was rewritten on 2026-10-15 to remove private work imagery and identifying work references. Branch names remain the same; commit IDs changed.

Use a fresh clone for continued development. Keep any old clone and local backups private. Copy only reviewed uncommitted changes or patches into the fresh clone; do not merge old history or push old branches/tags back into this repository.

The four old version tags were removed without publishing replacement versions. Installation from `main` remains available. Tag-based updates and pinned tag downloads are temporarily unavailable. Existing clones may retain their own local tags; the current updater only selects tags advertised by the remote.

No new release is approved by this cleanup. The original security-hotfix ancestry gate remains required, and a reviewed baseline migration is still needed before publishing another version.

GitHub pull-request refs, cached views, external clones and historical release records require separate follow-up. Rewriting branch history does not establish that those copies have been erased.
