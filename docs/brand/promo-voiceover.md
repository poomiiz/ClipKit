# EditorKrab promo: voice-over script

`docs/brand/promo.mp4` is a 33 s vertical (1080 × 1920) motion graphic with English captions and no sound.
Record or generate these lines (for example with CapCut's text-to-speech) and place each one at its start time.
The captions on screen show the same words, so the video also works muted.

| Start | End | Line |
|------:|----:|------|
| 0:00.3 | 0:04.3 | One long video. Hours of editing. |
| 0:04.6 | 0:08.4 | Meet EditorKrab. It turns long videos into ready-to-post shorts. |
| 0:08.6 | 0:13.4 | Drop in your video, and tell it what you want. |
| 0:13.6 | 0:18.4 | It transcribes the speech and splits it into stories. |
| 0:18.6 | 0:24.8 | One click adds subtitles, zoom cuts, emoji and music. |
| 0:25.0 | 0:28.8 | Export an MP4, or keep editing in CapCut. |
| 0:29.0 | 0:33.0 | EditorKrab. Edit less, post more. Free on GitHub. |

To change the picture, edit `scripts/make_promo.py` (the `LINES` list holds these times) and run
`python scripts/make_promo.py docs/brand/promo.mp4`.
