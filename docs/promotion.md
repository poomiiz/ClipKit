## GitHub release introduction

### English

EditorKrab helps prepare short videos from talking-head footage. It transcribes speech, cuts stories and creates a draft with subtitles and a cover. Review the result in CapCut or the local editor, then export an MP4.

This update records how long each step takes and helps compare manual editing with an EditorKrab draft. The guide uses matched sources and the same quality checklist for both methods; measured saving percentages are still pending.

Windows keeps its existing installer. Mac setup is experimental and uses CPU transcription. CapCut projects on Mac and team features still need testing with real users and devices.

Code and setup: [github.com/poomiiz/EditorKrab](https://github.com/poomiiz/EditorKrab)

## Community post

### English

I’m working on EditorKrab, an open source tool for preparing short-video drafts from talking-head footage. It handles transcription, story cuts, subtitles and covers, and leaves you an editable draft to review.

I’d like feedback from editors: where does the draft help, and what do you still spend time fixing? There’s a benchmark sheet for comparing it with manual editing using the same quality standard. We haven’t measured a real saving percentage yet.

Windows setup is available; Mac support is experimental. The code, setup guide and limitations are here: [github.com/poomiiz/EditorKrab](https://github.com/poomiiz/EditorKrab).
